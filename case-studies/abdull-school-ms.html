Abdull School MS: running a whole school from one dashboard

A school management system that brings students, teachers, classes and fees into one place, so school staff can run daily work from a single dashboard.

Role
Full-stack developer, UI design
Year
2025

React · TypeScript · Prisma
Status
Source code ↗
The problemWhat I didResultWhat I'd do next

The problem

Many schools keep student lists, timetables and fee payments in separate notebooks and spreadsheets. Finding who has paid, or which teacher has which class, takes time and leads to mistakes.

What I did

  1. 01One connected data model. Students, teachers, classes and payments are linked in one database with Prisma, so a change in one place shows up everywhere it matters.
  2. 02A dashboard for each role. Each person sees what they need: staff manage records, teachers see their classes, and the most common tasks are always one click away.
  3. 03Built the launch poster. The launch poster below introduces the system to schools in the same colours as the app.

Result

1dashboard for students, teachers, classes and fees
Opensource code on GitHub

Daily school work that used to be spread across notebooks now lives in one system, and the full code is public on GitHub for anyone to review.

What I'd do next

Next, I would add a parent portal with SMS fee reminders, and printable report cards generated straight from the grades.
