DHIIG KAAL: connecting blood donors with patients

A live web platform for blood donation in Somalia. Donors sign up with their blood type and location, and hospitals and families post requests that reach the donors who match.

Role
Full-stack developer, UI design
Year
2024 – 2025
Stack
PHP · MySQL · JavaScript
Status
Live site ↗
The problemWhat I didResultWhat I'd do next

The problem

When a patient needed blood, families phoned relatives and posted in WhatsApp groups, hoping someone with the right blood type would see it in time. There was no shared list of willing donors, so every emergency started the search from zero.

What I did

  1. 01One shared donor record. Every donor has a blood type, a location and an availability status, and every request carries the blood type, the hospital and how urgent it is. Matching the two lets the platform show only the donors who can actually help, closest first.
  2. 02Built for any phone and any connection. Light pages that load on slow mobile data, a registration form short enough to finish in a minute, and plain wording so anyone can use it under stress.
  3. 03Built the launch campaign. The poster below promotes registration; the same visual language runs through the site.

Result

24/7donor requests can be posted any time
Livein production at dhiigkaal.iftiinhub.com

DHIIG KAAL went live between 2024 and 2025 and runs in production today. Instead of starting from zero, a family or hospital can now post one request and reach registered donors with the right blood type straight away.

What I'd do next

Next, I would add SMS alerts so donors without smartphones still hear about urgent requests, and verify hospitals before they can post, so every request donors see is genuine.
